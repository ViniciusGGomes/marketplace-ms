# Marketplace Microservices - Checkout Service 🛒

Este repositório contém a implementação do **Checkout Service**, o microsserviço responsável por orquestrar o carrinho de compras e gerenciar a criação de ordens de pedido de forma altamente desacoplada e resiliente.

## 🏗️ Arquitetura e Papel no Ecossistema

O `checkout-service` atua como o **Producer (Produtor)** no ecossistema de mensageria assíncrona.
